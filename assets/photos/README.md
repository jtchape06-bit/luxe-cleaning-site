# Photography

Photos used by the site (JPG). Replace any file with a better one using the same name.

- `about.jpg`: About page (portrait)
- `kitchen.jpg`, `bathroom.jpg`, `living.jpg`: home page gallery
- `team1.jpg` to `team4.jpg`: home page team strip (portrait, 4:5)
- `<service-slug>.jpg`: photo at the top of each service page, e.g. `deep-cleaning.jpg`

A missing photo is simply left out of the page. Use JPGs at least 1200px wide, under 400 KB each.
